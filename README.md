# Responsive Internship Board

A responsive and accessible internship listing interface developed using HTML, CSS and JavaScript as part of the EdVyro Full Stack Development Internship – Task 1.

## Features

- Responsive layout for mobile, tablet and desktop.
- Reusable internship cards generated from JSON data.
- Search internships by keywords.
- Filter internships by domain.
- Empty and error states.
- Keyboard navigation support.
- Accessible form labels and controls.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON

## Project Structure

- index.html – Main webpage.
- style.css – Styling and responsive layout.
- script.js – Search, filters and interactive functionality.
- internships.json – Internship records.

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the project using a local web server.
4. Open the website in your browser.
